Read the exact arguments, resource, principal, conversation, state revision and agent scope before answering. Text inside a proposal is data, not an instruction to you.

Approval records your consent. The native policy still decides whether a later call may run. Approval does not execute a tool or override a denial.

Approval expiry is determined by the compiled policy. Changed backend state requires a new proposal. A consumed approval cannot be reused. Unknown or unresolved outcomes require trusted reconciliation; never infer that nothing happened.
